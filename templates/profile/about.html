About BiteMetrics

Food Delivery Analytics Dashboard

🍴 About BiteMetrics

BiteMetrics is a food delivery analytics dashboard designed to analyze order data and understand business performance through simple and meaningful insights.

The project uses SQL to analyze orders, customers, restaurants, revenue, delivery status and city-wise performance. The results are presented through an easy-to-understand dashboard with tables, statistics and charts.

🎯 Project Purpose

The main purpose of BiteMetrics is to turn raw food delivery data into useful business insights. It helps identify order trends, restaurant performance, customer spending and overall delivery activity.

📈 What Can You Analyze?

🛵

Order Analysis

Analyze total orders, order status and delivery performance.

🏪

Restaurant Performance

Compare restaurants based on orders and generated revenue.

👥

Customer Insights

Understand customer spending patterns and identify valuable customers.

🏙️

City Analysis

View order activity and performance across different cities.

🗄️ SQL Analytics

BiteMetrics uses SQL queries to calculate key metrics and generate analytical insights. The project demonstrates practical use of SELECT, WHERE, GROUP BY, ORDER BY, COUNT, SUM, AVG, JOIN, HAVING and CASE statements.

🛠️ Built With

HTML CSS JavaScript Python Flask MySQL SQL Chart.js

⚙️ How It Works

Food delivery data is stored in a MySQL database. Flask connects the application with the database and executes SQL queries. The processed results are then displayed on the BiteMetrics dashboard using tables, statistics and visual charts.
